# Brand

**Latchkit** is the working name: reusable engineering skills that attach to the coding tools a developer already uses.

Tagline: **Your agents. One workflow.**

The tone should be practical, direct, and welcoming to contributors. Lead with portable workflows, native Windows support, and inspectable configuration. Describe the initial release as a starter; reserve stronger reliability claims for published test evidence.

## Shortlist

| Name | Why it fits | Tradeoff |
|---|---|---|
| Latchkit | Short, pronounceable, and suggests a toolkit that attaches to existing agents. | Also resembles an ordinary hardware term. |
| Runweft | Suggests weaving workflows across agents; distinctive as a software name. | “Weft” may need explaining. |
| Weftdeck | Connects orchestration with the configuration frontend. | Less immediate to pronounce or spell. |
| Rivetrail | Suggests dependable execution with a trace of evidence. | Longer and slightly less conversational. |

## Preliminary screening

On September 5, 2026, live GitHub repository-name searches returned no matches for these four candidates, and their unscoped npm package endpoints returned HTTP 404. Exact web searches showed no obvious software collision; Latchkit also appears in unrelated hardware and craft contexts. These observations are preliminary, can change, and do not establish trademark, domain, organization-name, or package-name rights.

Names with observed overlap were excluded: [DevKeel](https://devkeel.com/) already describes a closely related agent workflow product; Keelkit has existing software references; Riglane has existing GitHub repositories. A repository under a personal GitHub account does not reserve an npm package or a domain.

Keep the product name separate from provider branding. Latchkit is an independent project and does not imply endorsement from Pilot Shell, Anthropic, OpenAI, Google, or Cursor.
